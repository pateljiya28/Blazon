BLAZON CLOCKS - IMAGE NAMING CONVENTION
========================================

Place your product images in this folder using the following naming convention.
The website uses placeholder divs until real images are added.

To replace placeholders with real images, swap each:
  <div class="product-image-placeholder">...</div>
with:
  <img src="images/FILENAME.jpg" alt="Model NAME" loading="lazy">

(For product pages in /products/ folder, use: src="../images/FILENAME.jpg")
